# DevOps Gym

Practice Linux and DevOps by resolving incident tickets in a disposable Ubuntu
container.

## Start

From this directory:

```text
terminal 1:  ./gym       # pick today's ticket
terminal 2:  ./run.sh    # enter a fresh lab
```

Solve and verify the incident, then review the follow-up questions.

Run `./gym --help` for the guide controls and direct-ticket syntax.
